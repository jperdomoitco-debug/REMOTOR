| Situación Actual |
| :---- |
| Actualmente, la empresa maneja la subcontratación de terceros tipo outsourcing para la ejecución de las licitaciones a través de rangos manuales dentro de archivos Excel de control de saldos. No se cuenta con una estructura maestra centralizada para registrar y administrar a estos proveedores, dependiendo de opciones estáticas o manuales que limitan la escalabilidad a medida que se incorporan nuevos actores (como el caso de DAZA, MERCADO o INTERNO). Al no existir un repositorio oficial, se dificulta asociar de forma limpia y estandarizada a las empresas o terceros subcontratados directamente con las órdenes de trabajo y el ciclo operativo correspondiente. |

| Situación Deseada |
| :---- |
| Implementar una maestra de subcontratistas robusta que reemplace los rangos manuales en Excel, permitiendo dar alta y gestionar a las empresas o terceros tipo outsourcing que participan en la ejecución de las licitaciones. |

**HU\_001 Creacion de subcontratistas**

| \# | Contexto | Criterios de Aceptación – Resultado / Comportamiento esperado |
| :---- | :---- | :---- |
| **1** | **Creacion de subcontratistas** | **Dado que:** Se requiere gestionar y centralizar las empresas o terceros bajo modalidad de outsourcing utilizados para la ejecución de las licitaciones, permitiendo su posterior asignación en las órdenes de trabajo. **Cuando:** Se requiere registrar un nuevo subcontratista en el sistema. **Entonces:**  Se debe permitir crear un registro en la maestra de subcontratistas contemplando los siguientes datos:  nombre o razón social  NIT o cédula  descripción ( para qué se subcontrata ) objeto o concepto |
