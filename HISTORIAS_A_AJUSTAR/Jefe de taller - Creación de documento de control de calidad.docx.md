| Situación Actual |
| :---- |
| Actualmente no se tiene un proceso de documentación claro del control de calidad, esto limita la capacidad de acompañar el control de calidad con evidencias que permitan a la entidad y área administrativa evidenciar la ejecución completa del trabajo.  |

| Situación Deseada |
| :---- |
| Es importante la toma de evidencias tanto de como llega el vehículo como él después de que el vehículo ha tenido la ejecución de las tareas. Esto permite una trazabilidad que en primer lugar permite consultar el histórico de las actividades realizadas en un vehículo en las diferentes órdenes de trabajo y en segundo lugar ofrece un comparativo con el que se puede añadir un OK o confirmación adicional de la finalización del servicio.  |

**HU\_001 Creación de documento de control de calidad**

| \# | Contexto | Criterios de Aceptación – Resultado / Comportamiento esperado |
| :---- | :---- | :---- |
| **1** | **Creación del control de calidad** | **Dado que:** Actualmente no se cuenta con un formato ni digital ni físico donde se pueda documentar la finalización de las actividades que comprende el cuadro de diagnóstico. **Cuando:** Se desea documentar el proceso de control de calidad **Entonces:** Dentro del mismo formulario de diagnóstico se permitirá realizar una creación ágil del control de calidad. Detallando de manera puntual si el trabajo fue completado de manera completa u otra información que sea de utilidad para el supervisor de la entidad. Logrando una conservación de la información de los trabajos realizados, permitiendo tener un histórico por cada placa, ofreciendo un abanico de posibilidades en cuanto a la creación de paneles informativos alimentados por flujos de inteligencia de negocios. |

**HU\_002 Notificar a la coordinadora administrativa la finalización del control de calidad**

| \# | Contexto | Criterios de Aceptación – Resultado / Comportamiento esperado |
| :---- | :---- | :---- |
| **1** | **Notificar a la coordinadora administrativa la finalización del control de calidad** | **Dado que:** Al completar el proceso de control de calidad no se tiene un documento especifico donde documente la información del control de calidad, sumado a que el jefe de taller debe desplazarse al área administrativa para confirmar la finalización del control de calidad. **Cuando:** Se complete el diligenciamiento del control de calidad. **Entonces** Se notificará automáticamente al coordinador administrativo la finalización de dicho control. Permitiendo proceder de manera oportuna procesos de actualización de saldos, confirmación a supervisor de la entidad y procesos de facturación.  |
